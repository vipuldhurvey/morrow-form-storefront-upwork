# Morrow & Form Storefront

A responsive ecommerce storefront concept with an editorial visual style. This personal portfolio demo shows product discovery patterns relevant to the frontend and ecommerce skills in Bipul Kumar's resume.

## Features

- Browse six fictional products across four categories.
- Filter by category, search product names, and sort by price or name.
- Add products to a shopping bag, change quantities, remove items, and see a live subtotal.
- Keep the demo bag in browser storage between visits on the same device.
- Responsive layouts, keyboard focus styles, a skip link, and a native accessible dialog.

## Run

Open `index.html` in a modern browser. No install, build step, external images, or account is required.

## Scope

Morrow & Form is a fictional store concept. Checkout is a nonfunctional demo message: there is no backend, inventory, shipping calculation, order submission, or payment processing.
